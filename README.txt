JAVA PROGRAMMING - ASSIGNMENT 1

All 8 questions from the supplied assignment image are included.
Every program has public class TEST and file src/TEST.java.
Java source files contain no comments.
Each question is a separate Eclipse-importable Java project.
This is a prepared Eclipse project layout, not a record of execution in Eclipse.
Requires JDK 8 or newer.

ECLIPSE IMPORT
1. Extract this ZIP.
2. Open Eclipse with your normal workspace.
3. File > Import > General > Existing Projects into Workspace > Next.
4. Select root directory: Java_Assignment_1.
5. Select all 8 projects. Select Copy projects into workspace if needed.
6. Click Finish.
7. Expand the required project > src > default package > TEST.java.
8. Right-click TEST.java > Run As > Java Application.
9. Enter input in the Console.

COMMAND LINE ARGUMENTS
Set_A_Q2 and Set_B_Q1 require command line arguments.
Run > Run Configurations > Java Application > select the question's configuration
> Arguments > Program arguments > enter a number > Apply > Run.
Included TEST.launch files supply sample arguments 12345 and 5 respectively.
You can also right-click TEST.launch > Run As > Java Application.
